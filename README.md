Tic Tac Toe
-----------
A simple Tic Tac Toe game made using HTML, CSS, and JavaScript.
Just a fun mini project where two players can play O vs X in the browser.

-->What it does
-Two player game (O and X)
-Shows winner when someone wins
-Shows draw if board is full
-Reset button to start again
-Clean and modern UI

-->Built With
-HTML
-CSS
-JavaScript

-->Project Files
-index.html
-css_file.css
-js_file.js

-->How to play
-Player O starts first
-Players take turns clicking boxes
-First to get 3 in a row wins
-If all boxes fill up → it’s a draw
-Click reset to play again
